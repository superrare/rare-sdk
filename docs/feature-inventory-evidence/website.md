Source: `/Users/keeganead/.codex/worktrees/fc3b/superrare-monorepo`, `services/superrare-com/src`. Source-only assessment, 2026-09-30. Repository and service AGENTS read. No production settings or live behavior checked. Paths below are relative to the monorepo root; `S/` means `services/superrare-com/src/`, `T/` means `S/app/api/trpc/[trpc]/`.

“Off” means no blockchain transaction is inherent in the user action. “Mixed” means an off-chain flow depends on blockchain reads or a verified transaction. Public browsing can display indexed blockchain information without requiring a connected wallet. Auth means the website session validated by `protectedProcedure` (`S/server/trpc.ts:isAuthed`); connecting a wallet alone is insufficient. Some authenticated operations additionally require a registered user ID. A source route/procedure does not establish production enablement.

## Feature gating and uncertainty

- `S/config/environment.ts` declares highlights, imported-contract removal, physical items/sell flow, NFT collaborations (client and server), creator posts, auction chat, lifecycle events, card payment and Ethereum network switch flags. Production flag values have not been observed.
- Mainnet drop creation requires approved artists through `assertAnnouncementArtist`; testnet explicitly bypasses that permission check.
- Creator post creation tRPC enforces session user ID and allowed uploaded-image URLs; UI says creator posts, but this handler alone does not prove artist-only eligibility. Downstream API policy is outside this website-only inventory.
- `/create/physical`, `/create/physical/partner` and `/create/digital/partner` are redirects to `/create`; inquiry procedures remain registered. `/create/release/[address]` redirects to `/create/release`. Legacy/marketing aliases are not independent implemented features.
- Registered procedures without a direct literal dotted-name match may be called through local aliases, helpers or generated integrations; the ledger labels this uncertainty. It does not equate absence of a string match with absence of UI.
- Admin and dev pages require individual route/layout checks before treating deployment access as public. No production browsing was done.
- No transactions were executed; chain classification derives from implementation responsibilities, not observed receipts.
